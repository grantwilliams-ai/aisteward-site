# aisteward.ai

AI Steward: Five Moves. One paragraph you can paste into your AI app or coding
agent, giving it five options: ask, disagree, pause, say no, end here.

`site/` is the deploy set. One HTML page, no build step, no frameworks. One small
inline script runs the Copy, Download and app-picker buttons and sends nothing.

No tracking, no cookies, no analytics.

The two paragraphs on the page (for chat apps and for coding agents) are in the
public domain (CC0 1.0). Paste them anywhere. No credit needed.

The study behind the page is at [graphometer.ai/kindness](https://graphometer.ai/kindness/).
